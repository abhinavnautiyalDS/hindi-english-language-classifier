# Hindi-English Language Classifier

Low-latency sentence-level classification for Hindi, English, and Hinglish text, designed for transcripts produced by Indian voice-agent STT systems.

## Train on real annotated data

The training pipeline uses **COMI-LINGUA**, an expert-annotated Hindi-English code-mixing dataset from the Lingo Research Group at IIT Gandhinagar. It downloads the official LID train/test CSVs, cleans the text, derives sentence-level classes from token-level language tags, removes exact train/test overlap, compares Logistic Regression with Linear SVM, and saves evaluation metrics.

```bash
python -m venv .venv
# Windows: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python scripts/build_dataset.py
python -m pytest -q
python train.py
streamlit run app.py
```

The source corpus is not committed to this repository. Raw and processed files are ignored by Git and recreated by the data build step. Dataset counts and cleaning decisions are written to `data/processed/dataset_audit.json`.

## Dataset and label design

See [DATASET_CARD.md](DATASET_CARD.md) for source, citation, licensing, label construction, and limitations.

Sentence labels are derived from token-level `hi` and `en` tags:
- Hindi token ratio >= 80%: `hindi`
- English token ratio >= 80%: `english`
- Otherwise: `hinglish`

This makes the three classes operationally useful for language selection, but the threshold is a project-defined aggregation rule—not a native sentence label supplied by the dataset.

## Evaluation

`models/evaluation.json` includes accuracy, macro-F1, per-class precision/recall/F1, confusion matrices, training time, and p50/p95 single-transcript classifier latency. It uses the official held-out source test split after cleaning and overlap removal.

**Do not confuse corpus evaluation with production validation.** The source is expert-annotated code-mixed text, not a representative sample of calls from your exact STT engine. Before production, evaluate on consented, anonymized, speaker-separated Hindi, Indian English, and Hinglish STT transcripts including real recognition errors, short turns, noisy audio, and regional speech variation. Keep that production test set separate from training.

## Run the API

After training:

```bash
uvicorn api:app --host 0.0.0.0 --port 8000
```

- `GET /health`
- `POST /predict` with JSON such as `{"text":"sir mujhe fees details chahiye"}`

## Streamlit deployment

Choose this repository, branch `main`, and entrypoint `app.py` in Streamlit Community Cloud. The model artifact is generated by the GitHub Actions training workflow.
